6. Limitations & scope

  • Final-state comparison: Measures the state difference before and after migrations. Intermediate states or delete-reinserts of identical keys/values are not tracked as distinct events.
  • Untested application code: Rehearsal executes SQL against disposable copies; it does not exercise application queries, ORM mapping hooks, or runtime transactions.
  • Declared scope: Tables without explicit primary keys, virtual tables, generated columns, and tables exceeding resource ceilings yield visible coverage gaps.
  • SQLite runtime: Rehearsal uses the local SQLite engine. It does not provide Cloudflare D1 or cloud runtime parity guarantees.
